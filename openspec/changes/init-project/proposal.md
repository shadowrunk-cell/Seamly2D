# Proposal: Initial Project Setup — SeamlyAI

## Why
Seamly2D — мощный open-source инструмент, но он страдает от:
1. Устаревшего UX, отпугивающего дизайнеров
2. Проблем с экспортом в CLO 3D (потеря кривых при конвертации)
3. Отсутствия AI-функций для автоматизации

Рынок требует решения, которое сочетает инженерную точность с современным UX и AI-ассистентом.

## What Changes
- **Форк Seamly2D** как база
- **AI-ассистент**: генерация лекал по эскизу, автоматическая градация, интеллектуальный подбор параметров
- **Исправленный экспорт**: корректный DXF-ASTM для CLO 3D, OBJ/FBX для Blender
- **Переработанный UI**: современный, интуитивный, адаптивный

## What Stays Same
- Параметрическое ядро и методики конструирования Seamly2D
- Открытая лицензия для базового функционала

## Impact
- **Пользователи**: получают доступный инструмент с AI-функциями
- **Разработчики**: форк позволяет независимо развивать продукт
- **Бизнес**: Freemium-модель с платными AI-функциями и облачными сервисами
